# 🧩 Features

## 🎨 UI & UX

- 🪟 Contains the liquid glass feel from **[Apple](https://youtu.be/jGztGfRujSE?si=SKBNCWc9_rU2l9Rm).**
- 🎨 Some default icon packs for you to love. Or install a new one.
- 🌗 Dark Mode/Light Mode Swap.
- ⚡ Smooth animations that don't slow your hardware.
- ✨ Everything centered and focused to make finding things too easy.

---

## 💾 Storage

- ✨ **Smart Storage**-A new way to store items effortlessly in no time, your sidebar compaion checks the app's category and then makes a folder that shows up on your taskbar and your file manager too!
- 🔐 **Archive Apps**-If you didn't use any app in 1 month, it will be archived and it will stop the app from taking any more space.
- 🔎 **Quick Search**-Find anything easily just by typing it's name, path or wildcards(like ‘**folder:date:10/10/2024**’).

---

## ✨ Special Features

- A Linux tool that makes **[.exe](https://www.google.com/m?q=What+are+.exe+files%3F&client=ms-opera-mobile&channel=new&espv=1)** files work like normal apps, check it **[here](https://winehq.org)**. Available pre-installed for test version and preset.
- ___Secret Feature___
- Split Screen (6 Windows Max)
- **Pin websites to taskbar** (like youtube.com pinned to the taskbar becomes YouTube app in your taskbar, works on all browsers
